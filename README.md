# VBA

## 이미지 로더 (modImageLoader.bas)

셀에 입력된 폴더경로 + 파일명을 기준으로 폴더 안의 이미지 파일(jpg, jpeg, png, gif, bmp, tif 등)을
자동으로 찾아 워크시트에 삽입/교체해주는 재사용 가능한 VBA 모듈입니다.

### 설치

1. 대상 엑셀 파일에서 `Alt+F11` 로 VBA 편집기를 엽니다.
2. `파일 > 파일 가져오기(Import File...)` 로 `modImageLoader.bas` 를 추가합니다.
   - 여러 엑셀 파일에서 공용으로 쓰려면 `개인용 매크로 통합 문서(Personal.xlsb)` 나
     `.xlam` 추가 기능으로 만들어 등록해두면 매번 Import할 필요 없이 재사용할 수 있습니다.
3. VBA 편집기에서 `InstallImageLoader` 매크로를 실행(F5)합니다.
   - `ImageConfig` 시트와 "이미지 업데이트" 버튼이 자동으로 생성됩니다.

### 사용법

`ImageConfig` 시트에 아래 항목을 행 단위로 입력합니다. (여러 행 = 여러 이미지)

| 컬럼 | 내용 |
|---|---|
| B: 폴더경로 | 이미지가 있는 폴더 경로 (예: `C:\Images`) |
| C: 파일명 | 확장자 생략 가능 (예: `product01`). 확장자를 포함해도 됩니다. |
| D: 표시위치 | 이미지를 넣을 셀 주소 (예: `E2`) |
| E: 표시시트명 | 이미지를 넣을 시트 이름. 비우면 `ImageConfig` 시트에 표시 |
| F, G: 너비/높이(pt) | 선택 입력. 비우면 D열 셀 크기에 맞춰 자동 조절 |

입력 후 **"이미지 업데이트"** 버튼을 누르면 각 행의 폴더/파일명에 해당하는 이미지를 찾아 삽입합니다.
폴더경로나 파일명을 바꾼 뒤 다시 버튼을 누르면 같은 위치의 이미지가 새 파일로 교체됩니다.
이미지를 더 추가하려면 `ImageConfig` 시트에 행을 추가하면 됩니다.

파일을 찾지 못했거나 삽입에 실패한 행은 H열(상태)과 완료 메시지에 표시됩니다.
